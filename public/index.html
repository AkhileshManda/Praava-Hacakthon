Integrate with one endpoint

Point Aura at your internal inventory API and we automatically map your SKUs.

const aura = new AuraAgent({
  apiKey: "aur_prod_9X3jf8L",
  webhookUrl: "https://your-wms.com/webhooks",
  integrations: {
    messaging: "linq",
    payments: "prava",
    knowledgeBase: "senso"
  }
});

await aura.startAutonomousOperations();
